# Dataset Detective — Amsterdam

## Dataset

I chose the "Stand van de bevolking" dataset from the City of Amsterdam.

The dataset contains information about:
- Age
- Sex
- Nationality
- Migration background
- Household type
- Marital status

The data is available for Amsterdam, districts and neighbourhoods.

## What is missing?

The dataset does not show every type of information about people.

For example, I did not find variables for:
- Education level
- Income
- Employment
- Disability
- Health conditions

This means the dataset alone cannot give a complete picture of the people living in Amsterdam.

## Areas

The dataset includes Amsterdam, districts and neighbourhoods.

Some older tables use area classifications that are no longer updated.

## Reflection

A dataset can look very complete but still leave out important information.

Before using a dataset for an AI project, I should check:
1. Who is included?
2. Which areas are included?
3. Which information is missing?
4. How old is the data?

Missing information can give an incomplete picture of a city.
